# HopperTheftProtection

Minecraft server plugin that prevents players from placing hoppers under containers that they don't have access to.

## Dependencies
- Bolt plugin has to be installed (https://modrinth.com/plugin/bolt)

## Config
No config needed XD, it's really simple, if the player does not have permission to withdraw items from the container, they won't be able to place hopper under it.

## Found bug?
Please submit issue here on github, don't forget to include version of this plugin, version of minecraft server you running and version of Bolt you running. It really helps speed up the debuging process. 

> [!NOTE]
> If you have been using the Kotlin version, all you need to do is to replace that plugin with this one.
